# 🚆 RailJet – Train Ticket Booking System with Interactive Seat Selection

RailJet is an IRCTC-inspired railway ticket booking web application built with **React JS** and **Vite**. Users can search trains between stations, choose a coach, pick their exact berth on a visual coach layout, enter passenger details, pay, and receive a booking confirmation with a PNR.

> Developed as a **Full Stack Development (FSD)** course project.

---

## ✨ Features

- **Train search** – select source, destination and travel date
- **Search results** – train name, number, departure/arrival time, duration and starting fare
- **Coach selection** – AC 3 Tier, AC Economy and Sleeper coaches (class-based pricing)
- **Interactive seat selection** – visual coach layout with bays, lower/middle/upper and side berths
  - Seat states: **Free**, **Yours (selected)** and **Booked**
  - Maximum **6 seats** per booking
  - Live fare calculation and booking summary
- **Login (demo)** – login modal with email and password validation; login is required before proceeding to payment
- **Passenger details** – name and age for each seat, plus a 10-digit contact number, with validation
- **Payment page** – UPI, Card and Net Banking options (simulated)
- **Booking confirmation** – PNR number, train, route, coach, seats, passenger list and contact number
- **Animated UI** – hero section with animated train, scroll-reveal animations, dark theme

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v16 or above)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/ArmaanAnas/railjet-train-booking.git

# Go to the project folder
cd railjet-train-booking
# Install dependencies
npm install

# Start the development server
npm run dev
```

Open the local URL shown in the terminal (usually `http://localhost:5173`).

### Build for production

```bash
npm run build
npm run preview
```

## 📝 Notes

- This is a **front-end demo project**. Train data is stored locally in `src/data.js`; there is no backend or database.
- Login accepts any valid email and a password of 4+ characters.
- Payment is simulated – no real transaction takes place.
- Booked seats are generated by a fixed formula to simulate occupancy.
